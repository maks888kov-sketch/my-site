# Помощник XFIT

Тестовый Android-помощник для XFIT STAFF (`ru.xfit.staff`).

Что делает:

1. Показывает кнопку «Удалить запись» только на карточке тренировки XFIT.
2. Запрашивает отдельное подтверждение.
3. Нажимает значок корзины.
4. Не подтверждает окончательное удаление в XFIT и не создаёт новую запись.

После установки откройте приложение, нажмите «Включить помощника», выберите
«Помощник XFIT» в специальных возможностях и разрешите работу. Затем откройте
XFIT STAFF через вторую кнопку.

Проект не изменяет XFIT STAFF, не получает пароли и не обходит серверные права.
